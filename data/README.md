# 数据目录说明

本目录按“指定官方渠道原始数据 → 清洗后建模数据”组织。空值表示尚未在题目指定渠道找到直接公布的实际值，不能直接按 0 处理。建模底表只保留蓟州区政府、天津市统计局、天津市文化和旅游局等题目允许渠道直接给出的数值，不使用反算值、合计拆分值或二手引用值。

## 可直接使用

- `processed/core_annual_2010_2025.csv`：2010—2025 年核心年度宽表。包含游客接待量、旅游综合收入、GDP、第三产业增加值、疫情虚拟变量和 2019 年统计口径断点。
- `processed/modeling_features_annual_2010_2025.csv`：在核心表基础上左连接收入、交通、精品民宿及限额以上住餐业特征，缺失项保持为空。
- `raw/accommodation_catering_2014_2024.csv`：限额以上住宿和餐饮业经营、客房、床位与餐位数据。

## 审计与补充

- `raw/official_indicator_ledger.csv`：核心指标逐条来源、口径和可信状态，是宽表的审计底表。
- `raw/auxiliary_indicator_ledger.csv`：居民收入、公路里程、精品民宿等候选解释变量。
- `raw/scenario_and_target_ledger.csv`：官方预计值、目标值和冲突口径。只能用于情景分析、边界约束或敏感性分析，不能冒充实际值。
- `raw/蓟州统计年鉴20xx.*`：下载保存的官方原始年鉴。
- `蓟州区全部统计月报.xlsx`：2022 年 9 月至 2026 年 6 月月报汇编。

## 关键口径提醒

1. 2019 年 GDP 及三产数据受第四次全国经济普查和统计范围调整影响，核心表已设置 `gdp_definition_break_2019=1`。
2. 2020—2022 年为疫情冲击期，核心表已设置 `covid_dummy=1`。
3. 游客人次单位为“万人次”，旅游综合收入和地区生产总值单位为“亿元”。
4. 缺失范围以 `processed/core_annual_2010_2025.csv` 的 `status=missing` 为准；不得用目标值、预计值或自行反算值填充。
5. 样本只有 16 个年度，建模时不宜一次放入过多解释变量；优先做时间序列/分段趋势，并用辅助变量做稳健性检验。

运行 `python scripts/build_core_dataset.py` 可从审计底表重建核心宽表。
